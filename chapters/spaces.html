Spaces of a Matrix

Rows, columns, null spaces, and the rank–nullity relationship

The idea. Start with a matrix as a linear map and build its fundamental subspaces from first principles.

Introduction#

In these notes, the row, column, and null spaces of a matrix are introduced informally and intuitively. We then explain the relationship between the rank and nullity of a matrix to develop a clearer understanding of these fundamental spaces.

The Fundamental Subspaces of a Matrix#

Consider the matrix \(A \in \mathbb{R}^{m \times n}\). We begin by establishing notation for \(A\) and \(A^{\top}\).

We write the matrix \(A\) in terms of its columns as:

\[A = \begin{bmatrix} \boldsymbol{c}_1 & \boldsymbol{c}_2 & \cdots & \boldsymbol{c}_n \end{bmatrix}\](01.1)

where \(\boldsymbol{c}_i \in \mathbb{R}^{m}\) for each \(i = 1,2,\cdots,n\). When we want to work with the rows of the matrix \(A\), we can always work with the columns of \(A^{\top}\) and therefore we write:

\[A^{\top} = \begin{bmatrix} \boldsymbol{r}_1 & \boldsymbol{r}_2 & \cdots & \boldsymbol{r}_m \end{bmatrix}\](01.2)

where \(\boldsymbol{r}_i \in \mathbb{R}^{n}\) for each \(i = 1,2,\cdots,m\). We can view \(A\) as a linear map from \(\mathbb{R}^{n}\) to \(\mathbb{R}^{m}\): for any \(\boldsymbol{x} = \left(x_1, x_2, \cdots x_n \right)\) we have,

\[A\boldsymbol{x} = \boldsymbol{c}_1 x_1 + \boldsymbol{c}_2 x_2 + \cdots + \boldsymbol{c}_n x_n\](01.3)

Therefore, for any \(\boldsymbol{x} \in \mathbb{R}^n\), we find \(A\boldsymbol{x} \in \mathbb{R}^m\). Similarly, for any \(\boldsymbol{y} \in \mathbb{R}^{m}\) such that, \(\boldsymbol{y} = \left( y_1, y_2, \cdots, y_m \right)\), we have,

\[A^{\top}\boldsymbol{y} = \boldsymbol{r}_1 y_1 + \boldsymbol{r}_2 y_2 + \cdots + \boldsymbol{r}_m y_m\](01.4)

Therefore, for any \(\boldsymbol{y} \in \mathbb{R}^m\), we find \(A^{\top}\boldsymbol{y} \in \mathbb{R}^n\). Collecting all possible vectors \(A^{\top}\boldsymbol{y}\), with \(\boldsymbol{y} \in \mathbb{R}^m\), gives a set that we denote by \(R(A)\). Thus,

\[R(A) = \{ A^{\top}\boldsymbol{y} : \boldsymbol{y} \in \mathbb{R}^m \}\](01.5)

It is clear that the set \(R(A) \subseteq \mathbb{R}^n\) is a vector space. Since this space is obtained by the linear combinations of rows of matrix \(A\), we call this the Row Space of \(A\). Now let us try to create a set of vectors orthogonal to the \(R(A)\). We can write such a set as, \(\{ x: \boldsymbol{a}^{\top}\boldsymbol{x} = 0, \forall \boldsymbol{a} \in R(A) \}\). Equivalently, this is the set of all vectors orthogonal to every linear combination of the rows of \(A\).

Therefore, for any member \(\boldsymbol{u}\) in the set described above we need to ensure,

\[\boldsymbol{u}^{\top}\left( \alpha_1 \boldsymbol{r}_1 + \alpha_2 \boldsymbol{r}_2 + \cdots + \alpha_m \boldsymbol{r}_m \right) = 0\](01.6)

for all \(\left( \alpha_1, \alpha_2, \cdots, \alpha_m \right) \in \mathbb{R}^m\). With appropriate choice of \(\alpha_i\) for \(i=1,2,\cdots,m\) we can easily see the following should hold true:

\[\begin{aligned} \boldsymbol{u}^{\top}\boldsymbol{r}_1 = 0 \\ \boldsymbol{u}^{\top}\boldsymbol{r}_2 = 0 \\ \vdots\\ \boldsymbol{u}^{\top}\boldsymbol{r}_m = 0 \end{aligned}\](01.7)

Combining these into a matrix form, we get,

\[\begin{bmatrix} \boldsymbol{r}_1^{\top}\\ \boldsymbol{r}_2^{\top}\\ \vdots\\ \boldsymbol{r}_m^{\top} \end{bmatrix} \boldsymbol{u} = \begin{bmatrix} 0\\ 0\\ \vdots\\ 0 \end{bmatrix}\](01.8)

Observe that the above can be easily written as follows:

\[A\boldsymbol{u} = \boldsymbol{0}\](01.9)

Therefore the set of vectors orthogonal to \(R(A)\), which we denote \(N(A)\) for reasons which will be clear, can succinctly be defined as follows:

\[N(A) = \{\boldsymbol{x} \in \mathbb{R}^n: A\boldsymbol{x}=\boldsymbol{0}\}\](01.10)

Observe that the above set is a vector space. We call it the null space of \(A\). The null space of \(A\) is orthogonal to the row space of \(A\).

Similarly, we can define the Column Space of \(A\), denoted as \(C(A)\), as the set of all linear combinations of columns of \(A\). It is easy to see that, \(C(A) = R(A^{\top})\). Therefore we can also conclude that \(C(A)\) is orthogonal to \(N(A^{\top})\).

Relating Rank and Nullity of a Matrix#

Let the matrix \(A \in \mathbb{R}^{m \times n}\) be of rank \(r\), the dimension of \(C(A)\) is therefore \(r\), which means that we can have a basis set consisting of \(r\) vectors for the \(C(A)\). From the equality of column rank and row rank of a matrix, we can say that a basis set consisting of \(r\) vectors can also be used to describe \(R(A)\).

Now suppose that the dimension of the null space of \(A\), also referred to as the nullity of \(A\), is \(k\).

Let us form a basis for this null space,

\[\mathit{\Gamma}_N = \{ \boldsymbol{g}_1, \boldsymbol{g}_2, \cdots, \boldsymbol{g}_k \}\](01.11)

Since the dimension of the domain space is \(n\), we can add \(l=n-k\) vectors to the above set so as to form a basis of \(\mathbb{R}^{n}\).

Let a complete basis for \(\mathbb{R}^n\) be

\[\mathit{\Gamma} = \{ \boldsymbol{g}_1, \boldsymbol{g}_2, \cdots, \boldsymbol{g}_k, \boldsymbol{p}_1, \boldsymbol{p}_2, \cdots, \boldsymbol{p}_l \}\](01.12)

For any element \(\boldsymbol{a}\) in the range of \(A\), equivalently in \(C(A)\), we have

\[\boldsymbol{a} = A\boldsymbol{x}\](01.13)

for some \(\boldsymbol{x} \in \mathbb{R}^n\).

We can write \(\boldsymbol{x}\) as a linear combination of the elements in the basis set \(\Gamma\) of \(\mathbb{R}^n\).

\[\boldsymbol{x} = \alpha_1 \boldsymbol{g}_1 + \alpha_2 \boldsymbol{g}_2+ \cdots + \alpha_k \boldsymbol{g}_k + \beta_1 \boldsymbol{p}_1 + \beta_2 \boldsymbol{p}_2 + \cdots \beta_l \boldsymbol{p}_l\](01.14)

Multiplying by \(A\) on both sides, we can write, \[\boldsymbol{a} = A\boldsymbol{x} = \beta_1 A\boldsymbol{p}_1 + \beta_2 A\boldsymbol{p}_2 + \cdots \beta_l A\boldsymbol{p}_l\](01.15)

(Since the \(\boldsymbol{g}_i\) form a basis for the null space of \(A\), we have \(A\boldsymbol{g}_i = \boldsymbol{0}\) for all possible values of \(i\).)

Thus, we can see that any vector in \(C(A)\) can be represented as a linear combination of the elements in the set \(\{A\boldsymbol{p}_1, A\boldsymbol{p}_2, \cdots, A\boldsymbol{p}_l \}\). Thus, the linear span of this set is \(C(A)\).

Let us try to see if we can prove that the above set is linearly independent. Towards this objective, let us try to look at a linear combination of the elements of the above set so that it equals the zero vector.

\[\delta_1 A\boldsymbol{p}_1 + \delta_2 A\boldsymbol{p}_2 + \cdots + \delta_l A\boldsymbol{p}_l = \boldsymbol{0}\](01.16)

From linearity property of \(A\) we have,

\[A\left[\delta_1 \boldsymbol{p}_1 + \delta_2 \boldsymbol{p}_2 + \cdots + \delta_l \boldsymbol{p}_l \right]= \boldsymbol{0}\](01.17)

The above implies that \(\delta_1 \boldsymbol{p}_1 + \delta_2 \boldsymbol{p}_2 + \cdots + \delta_l \boldsymbol{p}_l\) is in the null space of \(A\).

Therefore, we have,

\[\delta_1 \boldsymbol{p}_1 + \delta_2 \boldsymbol{p}_2 + \cdots + \delta_l \boldsymbol{p}_l = \gamma_1 \boldsymbol{g}_1 + \gamma_2 \boldsymbol{g}_2 + \cdots + \gamma_k \boldsymbol{g}_k\](01.18)

\[\delta_1 \boldsymbol{p}_1 + \delta_2 \boldsymbol{p}_2 + \cdots + \delta_l \boldsymbol{p}_l - \gamma_1 \boldsymbol{g}_1 - \gamma_2 \boldsymbol{g}_2 - \cdots - \gamma_k \boldsymbol{g}_k = \boldsymbol{0}\](01.19)

Since, \(\Gamma\) is a basis, it is a linearly independent set.

Thus, each \(\delta_i = 0\) for each \(i=1,2, \cdots,l\) and \(\gamma_j = 0\) for each \(j = 1,2, \cdots, k\).

Thus the set \(\{ A\boldsymbol{p}_1, A\boldsymbol{p}_2, \cdots, A\boldsymbol{p}_l \}\) is linearly independent.

Since the set is linearly independent and spans \(C(A)\), it is a basis for \(C(A)\).

Since rank of \(A\) is \(r\), we have, \(l = r\).

Thus, \(n = k + r\).

Thus, \(n = \dim(N(A)) + \dim(C(A))\).

Remark: In the rank–nullity identity, the column-space dimension can be replaced by the row-space dimension, since both equal the rank. Thus the row rank and the dimension of null space (nullity) are not independent and there is an easy relation between the two.
